## 📌 Overview

This project is an **End-to-End Bank Customer Churn Analysis** solution designed to identify the key factors contributing to customer churn and provide actionable business insights to improve customer retention.

The project uses:

- **Power BI** for interactive dashboards and data visualization
- **SQL** for data analysis and querying
- **Microsoft Excel** for data cleaning and preparation
- **DAX** for KPI calculations and business metrics
- **Power Pivot** for data modeling

The analysis covers **10,000 bank customers across 4 years** and evaluates customer behavior based on:

- Credit Score
- Geography
- Gender
- Age
- Tenure
- Account Balance
- Number of Products
- Credit Card Ownership
- Customer Activity
- Estimated Salary
- Customer Exit Status
- Bank Joining Date

### 🎯 Project Objective

The main objective is to identify customer segments with higher churn risk and provide **data-driven recommendations** that can help the bank improve customer retention, engagement, and overall business performance.
